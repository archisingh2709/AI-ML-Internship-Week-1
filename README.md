# Student Performance Prediction System

## Week 4 - Final AI/ML Project

### Project Overview

This project develops an end-to-end Machine Learning system for predicting student Mathematics scores.

The system uses student demographic and academic information to predict Mathematics performance.

## Problem Statement

Student performance depends on various factors such as study hours, attendance and performance in other subjects.

The objective of this project is to predict Mathematics scores using Machine Learning.

## Dataset

The dataset contains:

- Student ID
- Name
- Gender
- Age
- Study Hours
- Attendance
- Math Score
- Science Score
- English Score

## Project Workflow

1. Dataset Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Correlation Analysis
5. Feature Selection
6. Data Preprocessing
7. Model Training
8. Model Evaluation
9. Model Comparison
10. Student Score Prediction

## Machine Learning Models

- Linear Regression
- Random Forest Regression

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Jupyter Notebook

## Output

The system predicts the Mathematics score of a student based on:

- Age
- Study Hours
- Attendance
- Science Score
- English Score
- Gender
